# Example: falling spheres

Imitate, never copy. Shape: spheres (radial-gradient divs or Three.js canvas) fall with staggered springs, parallax depths, soft shadows scaling with height. For real 3D use the pinned Three.js CDN pattern (see web-3d); for faux-3D use gradients + blur(2-6px) on far layers. All t-driven.
