# Creative direction

One call, five decisions. Everything downstream (plan, presets, layout, skills) reads off this.

## 1. Intent (one sentence)

What the cut must ACHIEVE, not what it shows. "Make a $49 course feel like a $499 transformation in 5 seconds" beats "text animation with logo". If you can't name the job, you can't direct the cut.

## 2. Palette (three hues max)

Background + ink + ONE accent. Restraint reads premium; every extra hue halves the impact.

| Mood | bg | ink | accent |
|---|---|---|---|
| cinematic (default) | #0B0C10 | #F2F3F7 | #FFB340 |
| energetic | #101014 | #F4F2EC | #FF5A5A |
| playful | #1B1035 | #F4F2EC | #FF7AD9 |
| minimal | #F4F2EC | #141414 | #E4572E |
| elegant | #111214 | #EFE9DC | #D8B56B |
| tech | #0B0E14 | #E8EEF7 | #5AC8FA |

Dark stages forgive; light stages expose. Minimal gets ONE accent and no glow.

## 3. Font pair (voice, not decoration)

One display + one text (see `typography` pairings). The pairing IS the brand voice: Unbounded+Manrope (modern), Anton+Archivo (bold), Instrument Serif+Newsreader (elegant), Space Grotesk+Space Mono (tech).

## 4. Beat→preset map (motion with intent)

Every beat gets a preset id AND a reason: anticipation (weight), entrance (arrival), cascade (readability), counter-motion (depth), settle (landing), hold (resolve). A beat without a motion reason is decoration — cut it or justify it.

## 5. Layout strategy (see `layout-composition`)

center-stack (default hero), split-rail (text left, emblem right), mask (kinetic type), terminal (code), lower-third (broadcast). Pick from the BRIEF shape: code-ish → terminal, speaker → lower-third, short punchy → mask, everything else → stack/split by seed.

## Taste rules (non-negotiable)

- Restraint reads premium: one accent, one display face, one idea per beat.
- Motion earns attention: anticipation → overshoot → settle → breathing hold. A still frame with nice type is a poster, not a cut.
- Staging (Disney): the presentation of an idea so it is COMPLETELY and unmistakably clear. One focal element per beat; everything else supports or leaves.
- Exaggerate, then pull back 10%: sadder, bolder, snappier. Timid reads as broken.
