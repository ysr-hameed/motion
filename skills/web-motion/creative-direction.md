# Creative direction

Per brief: 1) intent in one sentence (what the cut must achieve). 2) palette: bg + ink + ONE accent (three hues max). 3) font pair: one display + one text. 4) beats mapped to presets (anticipation/entrance/cascade/settle/hold). 5) layout strategy (center-stack / split-rail / mask / terminal / lower-third). Taste rules: restraint reads premium (one accent, one display face, one idea per beat); motion earns attention (anticipation → overshoot → settle → breathing hold).
