# Messaging & chat UI

Bubbles cascade with per-message springs (stagger 8-12f). Typing indicator (3 dots, sine phase offsets) precedes each inbound bubble. Timestamps small mono. Phone frame optional (rounded rect chrome). Keep bubbles inside safe margins; latest bubble never under the badge.
