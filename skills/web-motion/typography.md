# Typography

Display: Anton, Bebas Neue, Archivo Black, Syne, Unbounded, Bricolage Grotesque, Fraunces, Instrument Serif, Bodoni Moda, Dancing Script, Caveat, Pacifico, Great Vibes, Satisfy, Shadows Into Light.
Text/UI: Karla, Archivo, Manrope, Outfit, Space Grotesk, Space Mono, Chivo.
ANY other Google family works too — cite it and the runtime loads it.

Pairings: modern Unbounded+Manrope, bold Anton+Archivo, playful Bricolage Grotesque+Karla, editorial Syne+Newsreader, elegant Instrument Serif+Newsreader, fashion Fraunces+Karla, futuristic Space Grotesk+Space Mono, poster Bebas Neue+Outfit, romantic Dancing Script/Great Vibes, marker Caveat/Pacifico.
One display + one text face per cut. Scripts render ~30% small — size at 1.4x, slight rotate. Never Inter/Roboto unless named. Never system stacks (validator error).
